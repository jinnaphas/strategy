# บันทึกดูงาน · EP Shanghai 2026

เว็บสำหรับมือถือ ให้ทีมดูงานบันทึกสิ่งที่ได้แต่ละวัน รับได้ทั้งข้อความ รูป และไฟล์
ทุกอย่างลงโฟลเดอร์ Google Drive ของผู้ดูแล แยกตามเมืองและผู้บันทึก

เปิดใช้งานที่ `https://jinnaphas.github.io/strategy/china-2026/`

```
มือถือทีม ──► หน้าเว็บนี้ (GitHub Pages, สาธารณะ: มีแค่โค้ด) ──► Apps Script (รันด้วยบัญชีผู้ดูแล) ──► Google Drive
                                                                                               │
                                                     Claude สรุปรายวันจาก Drive ผ่าน connector ◄┘
```

## หลักการ

- **repo นี้เป็นสาธารณะ** ในโฟลเดอร์นี้จึงมีแค่โค้ดหน้าเว็บ ไม่มีชื่อทีม รหัสทีม หรือ ID โฟลเดอร์
- รายชื่อทีมอยู่ใน Apps Script หน้าเว็บขอรายชื่อหลังตรวจรหัสทีมแล้ว และจำไว้ในเครื่อง
- ข้อมูลที่บันทึกทั้งหมดอยู่ใน Drive ของผู้ดูแล ไม่ผ่าน GitHub

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด: ใส่รหัสทีม → เลือกชื่อ → ถ่ายแล้วส่งเลย / พิมพ์ / แนบไฟล์ → แท็บของฉันและทีม |
| `sw.js` | เก็บหน้าเว็บไว้ในเครื่อง ให้เปิดได้แม้ไม่มีสัญญาณ (เปลี่ยนเลขเวอร์ชันทุกครั้งที่แก้ไฟล์) |
| `manifest.webmanifest`, `icon-*.png` | ให้เพิ่มลงหน้าจอโฮมแล้วเปิดได้เหมือนแอป |
| `apps-script/Code.example.gs` | ตัวอย่างตัวรับข้อมูล ใช้ค่าสมมติแทนชื่อและ ID โฟลเดอร์ ฉบับจริงเก็บไว้ใน Apps Script เท่านั้น |

ถ้า `API_URL` ใน `index.html` ยังว่าง หน้าเว็บจะทำงานใน **โหมดทดลอง** ข้อมูลอยู่ในเครื่องเท่านั้น และใช้ชื่อสมมติ

## ติดตั้ง

1. **Apps Script** — วางโค้ดฉบับจริงใน https://script.google.com ด้วยบัญชีเจ้าของโฟลเดอร์ Drive แก้ `TEAM_CODE` แล้วรัน `checkFolders` เพื่ออนุญาตสิทธิ์
2. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone** แล้วคัดลอก Web app URL
   แก้โค้ดภายหลัง: Deploy → Manage deployments → ✎ → Version: **New version** (URL เดิมใช้ต่อได้)
3. ใส่ URL ที่ `const API_URL = '...'` ใน `index.html` แล้วเปลี่ยนเลข `CACHE` ใน `sw.js`
4. ส่งลิงก์ส่วนตัวให้แต่ละคนทางแชทส่วนตัว รูปแบบ `.../china-2026/?code=<รหัสทีม>&me=<รหัสชื่อ>`
   ลิงก์นี้คงรหัสไว้ในแถบที่อยู่ เพื่อให้ไอคอนบนหน้าจอโฮมของ iPhone เปิดได้โดยไม่ต้องใส่ใหม่
5. ตั้งโฟลเดอร์ Drive เป็น **Restricted** (Apps Script บันทึกด้วยบัญชีผู้ดูแล ทีมไม่ต้องมีสิทธิ์ในโฟลเดอร์)
