# Strategy Radar — เกณฑ์การวิเคราะห์และให้คะแนน (Scoring Rubric)

## 1. ประเภทแรงขับของการเปลี่ยนแปลง (Driver: PESTEL+I)

| รหัส | ประเภท | ตัวอย่างสัญญาณ |
|---|---|---|
| **P** | Political / Policy | นโยบายรัฐ, แผนพลังงานชาติ, งบลงทุนภาครัฐ, ภูมิรัฐศาสตร์ |
| **E** | Economic | ดอกเบี้ย, ค่าเงิน, ราคาวัตถุดิบ/พลังงาน, การลงทุน, GDP |
| **S** | Social | พฤติกรรมผู้บริโภค, ประชากร, ตลาดแรงงาน, ทักษะ |
| **T** | Technological | AI, Smart grid, Storage, IoT, มาตรฐานเทคโนโลยีใหม่ |
| **En** | Environmental | Climate, Net zero, Carbon pricing, ภัยพิบัติ |
| **L** | Legal / Regulatory | กฎหมาย, ระเบียบ กกพ./หน่วยงานกำกับ, มาตรฐานบังคับ, PDPA |
| **I** | Industry | ความเคลื่อนไหวคู่แข่ง, ลูกค้ารายใหญ่, ซัพพลายเออร์, พันธมิตร, M&A, ประมูลงาน |

## 2. ด้านที่กระทบกลยุทธ์ (Impact Dimension)

| รหัส | ด้าน | คำถามที่ใช้ตรวจ |
|---|---|---|
| **D1** | ตลาดและอุปสงค์ (Market & Demand) | ขนาดตลาด/ความต้องการเพิ่มหรือลด? มีตลาดใหม่เกิดขึ้น? |
| **D2** | ลูกค้า (Customer) | ลูกค้าหลักเปลี่ยนแผน งบประมาณ วิธีจัดซื้อ หรือความต้องการหรือไม่? |
| **D3** | การแข่งขัน (Competition) | คู่แข่งเดิม/รายใหม่ทำอะไร? สินค้าทดแทน? ราคา? |
| **D4** | เทคโนโลยีและโมเดลธุรกิจ (Technology & Business Model) | เทคโนโลยีใหม่ทำให้วิธีสร้างคุณค่าเปลี่ยน? เกิด Platform/Ecosystem ใหม่? |
| **D5** | นโยบายและกฎระเบียบ (Policy & Regulation) | กติกาเปลี่ยนจนเปิด/ปิดโอกาส หรือเพิ่มต้นทุนการปฏิบัติตาม? |
| **D6** | ต้นทุนและซัพพลายเชน (Cost & Supply Chain) | ราคาวัตถุดิบ ค่าขนส่ง การขาดแคลนชิ้นส่วน |
| **D7** | การเงินและการลงทุน (Finance & Investment) | แหล่งเงินทุน ดอกเบี้ย สิทธิประโยชน์ BOI/ภาษี มูลค่าโครงการ |
| **D8** | คนและขีดความสามารถ (People & Capability) | ทักษะที่ต้องมี การแย่งตัวคนเก่ง การเปลี่ยนรูปแบบงานด้วย AI |
| **D9** | พันธมิตรและ Ecosystem (Partnership & Ecosystem) | โอกาสร่วมมือ, ผู้เล่นใหม่ใน ecosystem, การเปลี่ยนบทบาท orchestrator |
| **D10** | ESG และชื่อเสียง (ESG & Reputation) | ข้อกำหนด ESG, คะแนนความยั่งยืน, ความเสี่ยงชื่อเสียง |

## 3. ทิศทางของสัญญาณ (Direction)

- 🟢 **Opportunity** — เปิดโอกาสให้บรรลุเป้าหมายเร็วขึ้น/ใหญ่ขึ้น หรือเปิดทางใหม่
- 🔴 **Threat** — ทำให้บรรลุเป้าหมายยากขึ้น หรือทำให้สมมติฐานกลยุทธ์ไม่เป็นจริง
- 🟡 **Mixed / Watch** — ยังไม่ชัด หรือเป็นได้ทั้งสองทางขึ้นกับการตอบสนองของเรา

## 4. การให้คะแนน

### Impact — ผลกระทบต่อกลยุทธ์ (1–5)
| คะแนน | ความหมาย |
|---|---|
| 5 | เปลี่ยนเกม — กระทบเป้าหมายหลักของ Pillar หรือทำให้ต้องทบทวนทิศทางกลยุทธ์ |
| 4 | สูง — กระทบ KPI/เป้าหมายสำคัญของกลยุทธ์อย่างมีนัยสำคัญ (>10%) |
| 3 | ปานกลาง — กระทบแผนงาน/โครงการ ต้องปรับแนวทาง |
| 2 | ต่ำ — กระทบเล็กน้อย ข้อมูลประกอบ |
| 1 | แทบไม่กระทบ — เป็นบริบทเท่านั้น |

### Likelihood / Certainty — โอกาสที่ผลกระทบจะเกิดจริง (1–5)
| คะแนน | ความหมาย |
|---|---|
| 5 | เกิดขึ้นแล้ว / ประกาศเป็นทางการ / มีผลบังคับ |
| 4 | มีแผนชัดเจน มีงบประมาณ/ไทม์ไลน์ |
| 3 | อยู่ระหว่างพิจารณา/ร่าง มีหลายแหล่งยืนยัน |
| 2 | แนวโน้มหรือความเห็น ยังไม่มีการตัดสินใจ |
| 1 | ข่าวลือ / แหล่งเดียวที่ความน่าเชื่อถือต่ำ |

### Priority Score = Impact × Likelihood
| Score | ระดับ | การดำเนินการ |
|---|---|---|
| **15–25** | 🔥 Critical | แจ้ง CEO/EC ภายในสัปดาห์ เสนอการตัดสินใจ/การตอบสนอง |
| **8–14** | ⚠️ High | นำเข้าวาระทบทวนกลยุทธ์รายเดือน มอบเจ้าของกลยุทธ์ประเมินเชิงลึก |
| **4–7** | 👁️ Monitor | ติดตามต่อเนื่อง ใส่ในรายการเฝ้าระวัง |
| **1–3** | 📄 Log | บันทึกใน signal log เท่านั้น |

### Time Horizon — ผลกระทบจะเกิดเมื่อไร
| รหัส | ช่วงเวลา |
|---|---|
| **H0** | ทันที (< 3 เดือน) |
| **H1** | ภายใน 1 ปี |
| **H2** | 1–3 ปี |
| **H3** | มากกว่า 3 ปี |

### Confidence — ความเชื่อมั่นในข้อมูล
- **สูง** — แหล่ง Tier A หรือ Tier B ≥ 2 แหล่งยืนยัน
- **กลาง** — Tier B 1 แหล่ง หรือ Tier C หลายแหล่ง
- **ต่ำ** — Tier C/D แหล่งเดียว → ต้องระบุ "ต้องตรวจสอบ"

## 5. รูปแบบบันทึกสัญญาณ (Signal Record)

```
[SIG-YYYYMMDD-NN] หัวข้อสัญญาณ
- วันที่/แหล่ง: YYYY-MM-DD · สำนักข่าว (Tier X) · URL
- ข้อเท็จจริง: ...
- Driver: P/E/S/T/En/L/I
- กระทบกลยุทธ์: [ID] ชื่อ → D# ด้าน → 🟢/🔴/🟡
- กลไก: ข่าวนี้ → ... → กระทบ KPI ...
- สมมติฐาน: [A#] ถูกท้าทาย/สนับสนุน
- คะแนน: Impact x · Likelihood y = Score z · Horizon H# · Confidence สูง/กลาง/ต่ำ
- So what: ...
- Now what: ... (ผู้รับผิดชอบที่เสนอ: ...)
```
