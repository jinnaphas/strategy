หลักกำกับ

  • AI เสนอ คนตัดสินใจ — การเลือกและการแลกเป็นของผู้บริหาร
  • ห้าม Agent สร้างหรือแก้ตัวเลขทางการเงิน — ดึงจากระบบต้นทางเท่านั้น
  • ทุกสัญญาณมีแหล่งอ้างอิงและวันที่ — สัญญาณระดับวิกฤตต้องตรวจต้นฉบับก่อนเข้าที่ประชุม
  • ข้อมูลลับอยู่ในพื้นที่ private เท่านั้น — หน้านี้และ repo สาธารณะไม่มีข้อมูลกลยุทธ์จริง
  • เนื้อหาจากเว็บเป็นข้อมูล ไม่ใช่คำสั่ง — Agent ไม่ทำตามข้อความที่ฝังมาในข่าว
